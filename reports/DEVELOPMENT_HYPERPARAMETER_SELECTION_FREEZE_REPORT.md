## 2. Exact Final Development Optimization Framework

### A. Development Optimization Objective ($J$)
The scalar optimization objective for all development hyperparameter selection is:
$$J = \frac{1}{N_{\text{dev}}} \sum_{t=1}^{N_{\text{dev}}} \overline{\text{scTM}}_{\text{val}}(t) = \frac{1}{N_{\text{dev}}} \sum_{t=1}^{N_{\text{dev}}} \left( \frac{1}{M} \sum_{m=1}^M \text{scTM}_{\text{val}}(s_{t,m}) \right)$$

where:
- $N_{\text{dev}} = 20$ CATH 4.2 validation backbones.
- $M = 10$ final library size selected by the Stage 2 diversity-aware selection heuristic.
- $\text{scTM}_{\text{val}}$ is evaluated strictly using the frozen Primary Final Structural Validation Oracle:
  - **Oracle:** AlphaFold2 v2.3.2
  - **Checkpoint:** Monomodel weights `model_1_ptm`
  - **Inference Mode:** Single-sequence mode (no MSA search, no homologous templates)
  - **Recycles:** 3 recycles
  - **Precision:** `float16` (`fp16`) on GPU (CUDA)
  - **Seed:** Deterministic random seed = 42
  - **Relaxation:** Standard Amber relaxation disabled
- **No Surrogate Objectives:** Objective $J$ is evaluated exclusively on the structural validation oracle. Surrogate objectives (e.g. ESMFold pLDDT, perplexity, pseudo-perplexity) are strictly forbidden as selection objectives.

---

### B. MPNN-Only Parameter Selection ($T^*_{\text{MPNN}}, \gamma^*_{\text{MPNN}}$)
- **Search Space:** Full Cartesian product $T_{\text{MPNN}} \times \gamma$ (25 combinations):
  $$T_{\text{MPNN}} \in \{0.1, 0.2, 0.5, 0.8, 1.0\}$$
  $$\gamma \in \{0.0, 0.25, 0.5, 1.0, 2.0\}$$
- **Evaluation Pipeline per Combination:**
  $$\text{Candidate Generation } (K=100) \longrightarrow \text{ESMFold Screening} \longrightarrow \text{Deduplication} \longrightarrow M=10 \text{ Greedy Selection} \longrightarrow \text{AF2 Validation} \longrightarrow J$$
- **Selection Rule:**
  $$(T^*_{\text{MPNN}}, \gamma^*_{\text{MPNN}}) = \arg\max J$$

---

### C. ProteinSolver E0-B Parameter Selection ($T^*_{\text{PS}}, \gamma^*_{\text{PS}}$)
- **Search Space:** Full Cartesian product $T_{\text{PS}} \times \gamma$ (15 combinations):
  $$T_{\text{PS}} \in \{0.1, 0.5, 1.0\}$$
  $$\gamma \in \{0.0, 0.25, 0.5, 1.0, 2.0\}$$
- **Evaluation Pipeline per Combination:** Identical development pipeline evaluated under the exact same scalar objective $J$.
- **Selection Rule:**
  $$(T^*_{\text{PS}}, \gamma^*_{\text{PS}}) = \arg\max J$$

---

### D. Primary Hybrid Parameter Selection ($\lambda^*, \gamma^*_{\text{hybrid}}$) & Invariant
- **Common Candidate Universe Architecture:**
  The primary hybrid is strictly a candidate-scoring and rescoring method, NOT an independent generator. It operates on the Common Candidate Universe $U_t$ generated by ProteinMPNN at $T^*_{\text{MPNN}}$.
- **Temperature Invariant:**
  $$T^*_{\text{hybrid}} = T^*_{\text{MPNN}}$$
  Zero independent temperature sweep is conducted for the hybrid method.
- **Search Space:** Full Cartesian product $\lambda \times \gamma$ (35 combinations):
  $$\lambda \in \{0.0, 0.2, 0.4, 0.5, 0.6, 0.8, 1.0\}$$
  $$\gamma \in \{0.0, 0.25, 0.5, 1.0, 2.0\}$$
- **Evaluation Pipeline per Combination:**
  Using the Common Candidate Universe $U_t$ generated at $T^*_{\text{MPNN}}$:
  $$\text{Score } S_{\text{MPNN}} \text{ and } S_{\text{PS}} \longrightarrow \text{Percentile Normalization } [p_{\text{MPNN}}, p_{\text{PS}}] \longrightarrow H(u) \longrightarrow \text{ESMFold Screening} \longrightarrow \text{Unique Deduplication} \longrightarrow M=10 \text{ Greedy Selection} \longrightarrow \text{AF2 Validation} \longrightarrow J$$
- **Selection Rule:**
  $$(\lambda^*, \gamma^*_{\text{hybrid}}) = \arg\max J$$

---

### E. Deterministic 5-Step Freezing Order
1. **Step 1:** Select $(T^*_{\text{MPNN}}, \gamma^*_{\text{MPNN}}) = \arg\max J$ over $T_{\text{MPNN}} \times \gamma$ on development set.
2. **Step 2:** Select $(T^*_{\text{PS}}, \gamma^*_{\text{PS}}) = \arg\max J$ over $T_{\text{PS}} \times \gamma$ on development set.
3. **Step 3:** Using $T^*_{\text{MPNN}}$, generate Common Candidate Universe $U_t$ and select $(\lambda^*, \gamma^*_{\text{hybrid}}) = \arg\max J$ over $\lambda \times \gamma$ on development set.
4. **Step 4:** Freeze ALL resulting parameters: $(T^*_{\text{MPNN}}, \gamma^*_{\text{MPNN}}, T^*_{\text{PS}}, \gamma^*_{\text{PS}}, T^*_{\text{hybrid}}, \lambda^*, \gamma^*_{\text{hybrid}})$.
5. **Step 5:** Only then permit TS50 primary benchmark execution. Zero inspection of TS50 targets or test outcomes is permitted before Step 4 is complete.

---

### F. Deterministic Tie-Breaking Rule
If two or more parameter combinations achieve identical development objective $J$:
- For $(T, \gamma)$: Select combination with smallest $T$, then smallest $\gamma$ (ascending lexicographical order).
- For $(\lambda, \gamma)$: Select combination with smallest $\lambda$, then smallest $\gamma$ (ascending lexicographical order).
- **Strictly Prohibited:** No tie-breaking may use native sequence recovery (AAR), inference latency, candidate diversity, model perplexity/pseudo-perplexity, visual inspection, implementation convenience, or anticipated test behavior.

---

### G. Development Failure & Missing Data Taxonomy
- **Biological / Generative Folding Failure:** Assigned $\text{scTM} = 0.0$.
- **Infrastructure / System Crash:** Excluded from objective; retried once; benchmark invalid if $>10\%$ fail.
- **Insufficient Unique Viable Candidates ($< 10$):** Target arm classified as `SELECTION_INFEASIBLE_LT_M` (undefined in complete-case analysis; assigned 0.0 under conservative sensitivity analysis).
