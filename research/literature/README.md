# LITERATURE AUDIT REPOSITORY

This directory houses individual paper summaries, reading notes, and structured analyses following the protocol outlined in `RESEARCH_PROTOCOL.md`.

Each paper audited during the project receives a dedicated markdown summary file named `<paper_id>.md` (corresponding to the `paper_id` column in `research/literature_matrix.csv`).
